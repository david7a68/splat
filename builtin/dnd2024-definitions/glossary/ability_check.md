# Ability Check

<!-- SRD page 176 -->

An ability check is a D20 Test that represents using\
one of the six abilities—or a specific skill associated\
with an ability—to overcome a challenge. See also\
“Playing the Game” (“D20 Tests” and “Proficiency”).\
